# 第一试卷网下载器 - Web Edition

一款现代化的 Web 应用，用于从 [第一试卷网](https://www.shijuan1.com/) (www.shijuan1.com) 浏览、搜索和下载各学科、各年级试卷资源。

采用苹果 iOS 风格设计，侧边栏导航 + 卡片式布局，支持 5 套主题配色，所有图标使用高精度内联 SVG，无需安装任何依赖，浏览器即可使用。

## 功能特性

### 试卷浏览
- **9 大学科分类** — 语文、数学、英语、物理、化学、政治、历史、地理、生物
- **全年级覆盖** — 从小学一年级到高考试卷，每个学科包含对应的年级分类
- **学科卡片** — 高精度 SVG 图标，每个学科独立配色，直观展示分类；9 个分类单行排列，紧凑布局
- **年级标签栏** — 选中学科后展示该学科所有年级，一键切换
- **分页浏览** — 支持上一页/下一页/跳转指定页，显示总页数和总条数
- **真实文件格式识别** — 网站元数据中的"文件类型"经常与真实文件不符（如标注 `.doc` 实为 `.rar`），浏览页会异步抓取详情页以下载地址扩展名纠正显示，确保下载文件名后缀正确

### 搜索
- **关键词搜索** — 输入试卷关键词（如"期中"、"期末"、"高考"）进行全站搜索
- **搜索历史** — 自动记录最近 20 条搜索记录，支持一键清除
- **分页结果** — 搜索结果支持分页浏览

### 下载
- **一键下载** — 在试卷卡片或详情弹窗中直接点击下载
- **批量下载** — 浏览/搜索结果页全选/反选后批量下载
- **自动命名** — 文件名格式为 `试卷标题.扩展名`，自动清理非法字符
- **真实扩展名** — 始终以下载地址的扩展名为准命名文件，不受网站元数据误导（避免 `.doc` 实为 `.rar` 时命名错误）
- **下载管理** — 实时状态跟踪（下载中/已完成/失败），支持打开文件、定位文件、删除
- **本地保存** — 通过 Windows 原生文件夹选择器指定保存路径
- **磁盘空间检查** — 下载前自动检查磁盘剩余空间，空间不足时拒绝写入

### 收藏
- **试卷收藏** — 浏览/搜索时一键收藏试卷
- **收藏管理** — 收藏列表支持单独下载、移除、全部下载

### 界面
- **iOS 风格设计** — 简洁现代的 UI，侧边栏导航 + 卡片式布局
- **5 套主题** — 浅色（默认）、深色、海洋蓝、玫瑰金、森林绿
- **高清 SVG 图标** — 所有图标使用内联 SVG，学科图标、文件类型图标均为高清矢量图
- **文件类型图标** — 根据 .doc/.rar/.pdf/.ppt/.xls 等扩展名显示不同颜色的文件图标
- **响应式布局** — 适配桌面和移动设备
- **零依赖** — 仅使用 Node.js 内置模块，无需 `npm install`

## 快速开始

### 环境要求

- **Node.js** v14+（仅使用内置模块，无需安装依赖）
- **Windows 操作系统**（文件夹选择、打开文件、磁盘空间查询依赖 PowerShell）

### 启动方式

**方式一：批处理脚本（推荐）**

双击 `start.bat`，脚本会自动检查 Node.js 环境、启动服务器并打开浏览器。

**方式二：命令行**

```bash
cd shijuan1-downloader
node server.js
```

然后在浏览器中打开 [http://localhost:3211](http://localhost:3211)。

### 无需安装依赖

服务器仅使用 Node.js 内置模块（`http`、`https`、`fs`、`path`、`url`、`child_process`、`os`），零依赖运行。`package.json` 中无任何外部依赖。

## 网站结构分析

### 编码

第一试卷网使用 **gb2312** 字符编码（非 UTF-8），所有页面在 `<meta>` 中声明 `charset=gb2312`。这是本下载器需要解决的核心技术挑战——Node.js 原生不支持 gb2312 解码，需要特殊处理。

### 学科与年级分类

网站使用路径前缀区分学科，年级代码附加在学科前缀后：

| 学科 | 路径前缀 | 包含年级 |
|------|---------|---------|
| 语文试卷 | `sjyw` | 1-9年级、中考(zk)、高一-高三(g1-g3)、高考(gk) |
| 数学试卷 | `sjsx` | 1-9年级、中考、高一-高三、高考 |
| 英语试卷 | `sjyy` | 1-9年级、中考、高一-高三、高考 |
| 物理试卷 | `sjwl` | 8-9年级、中考、高一-高三、高考 |
| 化学试卷 | `sjhx` | 9年级、中考、高一-高三、高考 |
| 政治试卷 | `sjzz` | 7-9年级、中考、高一-高三、高考 |
| 历史试卷 | `sjls` | 7-9年级、中考、高一-高三、高考 |
| 地理试卷 | `sjdl` | 7-8年级、中考、高一-高三、高考 |
| 生物试卷 | `sjsw` | 7-8年级、中考、高一-高三、高考 |

年级代码对照：

| 代码 | 含义 | 代码 | 含义 |
|------|------|------|------|
| 1-6 | 小学一年级至六年级 | zk | 中考试卷 |
| 7-9 | 初中七年级至九年级 | g1 | 高一 |
| g2 | 高二 | g3 | 高三 |
| gk | 高考试卷 | | |

栏目路径格式：`/a/{学科前缀}{年级代码}/`，例如：
- 语文一年级：`/a/sjyw1/`
- 数学高考试卷：`/a/sjsxgk/`
- 物理八年级：`/a/sjwl8/`

### 列表页结构

列表页 URL 格式：
- 第一页：`/a/sjyw1/`
- 后续页：`/a/sjyw1/list_{typeid}_{page}.html`（typeid 从第一页分页链接中提取）

列表页使用 HTML `<table>` 表格展示试卷，每行包含：

| 列 | 内容 | 示例 |
|----|------|------|
| 资源名称 | 标题链接 | `<a href="/a/sjyw1/332513.html" class="title">统编版2025学年一年级语文下册期中达标测试卷</a>` |
| 文件类型 | 扩展名 | `.doc` |
| 所属栏目 | 分类链接 | 一年级 |
| 版本 | 教材版本 | 人教版 |
| 大小 | 文件大小 | `0.17 MB` |
| 上传日期 | 发布日期 | `2025-03-25` |

分页信息位于 `<div class="dede_pages">` 中，格式为 `共 <strong>90</strong>页<strong>2239</strong>条`。

### 详情页结构

详情页 URL 格式：`/a/sjyw6/334332.html`

详情页包含以下信息区块：

1. **标题**：`<div class="title"><h2>试卷标题</h2></div>`
2. **信息列表**：`<div class="infolist">` 内含编号、教材版本、资源类型、资源大小、文件类型、发布时间、授权方式
3. **下载地址**：`<ul class="downurllist"><li><a href="/uploads/soft/..." target="_blank">本地下载</a></li></ul>`

下载链接为网站直链，格式如 `/uploads/soft/sj2025/yuwen/6/1-260211103056.rar`，拼接 `https://www.shijuan1.com` 前缀即可直接下载。

> ⚠️ **重要**：详情页 `<div class="infolist">` 中的"文件类型"字段经常与真实文件**不一致**（如标注 `.doc` 实际下载的是 `.rar`）。本下载器以下载地址的扩展名为真实文件格式，覆盖元数据中的 `fileType`。

### 搜索机制

第一试卷网本身**没有提供站内搜索接口**（`/plus/search.php` 等常见路径均返回 404）。本下载器采用**深度分类搜索**方案替代：

1. 用户选择一个学科（如"语文试卷"）并输入关键词
2. 服务器**并发抓取**该学科所有年级分类的第一页（如语文的 14 个年级分类）
3. 在抓取到的试卷列表中按标题关键词过滤
4. 可选抓取后续页（`maxPages` 参数控制，默认 2 页）进一步扩大搜索范围

搜索 API 参数：
- `keyword`：搜索关键词
- `subject`：学科 key（如 `yuwen`）
- `maxPages`：每个年级分类抓取的最大页数（默认 2）

由于采用并发请求，搜索 14 个年级分类的第一页仅需约 1-2 秒。

## 实现方案

### gb2312 编码转换

第一试卷网使用 gb2312 编码，而现代浏览器和 Node.js 默认使用 UTF-8。本下载器采用三级降级策略处理编码转换：

1. **首选：TextDecoder（Node 18+）**
   - Node.js 18+ 的 `TextDecoder` 支持 `gb18030` 编码（gb18030 是 gb2312 的超集，完全兼容）
   - 性能最佳，纯 JavaScript 实现，无需外部进程

2. **兜底：PowerShell 转换**
   - 对于 Node.js 14-17 不支持 TextDecoder 的环境
   - 通过 PowerShell 调用 .NET 的 `System.Text.Encoding.GetEncoding('gb2312')` 进行转换
   - 将原始字节写入临时文件，PowerShell 读取后以 UTF-8 输出

3. **最终兜底：latin1**
   - 如果以上方法都失败，使用 latin1 编码读取（中文会显示为乱码，但不会崩溃）

### 列表页解析

使用正则表达式从 HTML 表格中提取试卷信息：

```javascript
// 匹配表格行中的标题链接
const rowRe = /<tr\s*>[\s\S]*?<a\s+href="([^"]+)"\s+class="title"[^>]*>([^<]+)<\/a>[\s\S]*?<\/tr>/g;

// 提取各列数据
const cells = row.match(/<td[^>]*>([^<]*)<\/td>/g);
// cells[1]=文件类型, cells[3]=版本, cells[4]=大小, cells[5]=日期
```

分页信息提取：

```javascript
const pageMatch = html.match(/共\s*<strong>(\d+)<\/strong>页\s*<strong>(\d+)<\/strong>条/);
// totalPages = pageMatch[1], totalItems = pageMatch[2]
```

typeid 提取（用于翻页 URL 构造）：

```javascript
const typeIdMatch = html.match(/list_(\d+)_\d+\.html/);
// typeId = typeIdMatch[1]
```

### 详情页解析

从详情页提取下载链接：

```javascript
const dlMatch = html.match(/<ul class="downurllist">[\s\S]*?<a\s+href="([^"]+)"[^>]*>([^<]*)<\/a>/);
// downloadUrl = dlMatch[1]
```

**真实文件格式纠正**：网站元数据中的"文件类型"经常与真实文件不符，以下载地址扩展名为准：

```javascript
const extMatch = downloadUrl.split('?')[0].match(/\.([a-zA-Z0-9]+)$/);
if (extMatch) {
  info.fileType = '.' + extMatch[1].toLowerCase();  // 覆盖元数据中的 fileType
  info.realFileType = info.fileType;
}
```

### 下载流程

```
用户点击下载
    │
    ├─ 有 downloadUrl? ──否──→ 调用 /api/detail 获取详情页解析下载链接
    │                                  │
    │    是                             ▼
    ▼                          得到 downloadUrl
构造文件名（标题 + 真实扩展名）
    │  └─ 扩展名始终取自 downloadUrl 的 URL 扩展名，
    │     不使用网站元数据中的 fileType（避免 .doc 实为 .rar 时命名错误）
    ▼
添加到下载列表（状态: downloading）
    │
    ▼
调用 /api/save-file 下载并保存到磁盘
    │
    ├─ 成功 ──→ 更新状态为 done，记录 filePath
    │
    └─ 失败 ──→ 更新状态为 failed，记录错误信息
```

### 真实文件格式补全

浏览页/搜索页渲染列表后，前端会异步调用 `/api/batch-detail` 批量抓取详情页，以下载地址扩展名纠正卡片上的文件类型图标和标签：

```
列表渲染（先用网站元数据显示 .doc）
    │
    ▼
enrichFileTypes() 异步调用 /api/batch-detail
    │  └─ 并发抓取当前页所有试卷的详情页（单次上限 40 条）
    ▼
以下载地址扩展名覆盖 fileType（如 .doc → .rar）
    │
    ▼
updateCardsFileType() 局部更新卡片图标与标签（无需重新渲染列表）
```

### 文件管理

所有文件操作通过 PowerShell 实现 Windows 原生功能：

- **文件夹选择**：`System.Windows.Forms.FolderBrowserDialog`
- **打开文件**：`Start-Process -FilePath`
- **定位文件**：`Start-Process explorer.exe -ArgumentList '/select,"path"'`
- **删除文件**：`fs.unlinkSync`
- **磁盘空间**：`fs.statfsSync`（Node 18+）或 `Get-PSDrive`（兜底）

PowerShell 脚本均以 UTF-8 BOM 编码写入临时文件，确保中文路径正确处理。

## API 接口参考

### `GET /api/categories`
返回所有学科和年级分类配置。

**响应示例：**
```json
{
  "yuwen": {
    "name": "语文试卷",
    "prefix": "sjyw",
    "grades": [
      {"code": "1", "name": "一年级", "path": "/a/sjyw1/"},
      {"code": "zk", "name": "中考试卷", "path": "/a/sjywzk/"}
    ]
  }
}
```

### `GET /api/list?subject={subject}&grade={grade}&page={page}`
获取指定学科和年级的试卷列表。

**参数：**
- `subject`：学科 key（如 `yuwen`、`shuxue`）
- `grade`：年级代码（如 `1`、`zk`、`gk`）
- `page`：页码（从 1 开始）

**响应示例：**
```json
{
```

## 使用说明

### 浏览试卷

1. 打开应用后默认进入「试卷浏览」页面
2. 点击学科卡片（如「语文试卷」）选择学科
3. 在年级标签栏中点击目标年级（如「一年级」）
4. 试卷列表自动加载，点击「上一页/下一页」翻页
5. 点击试卷卡片或「详情」按钮查看试卷详情
6. 点击「下载」按钮直接下载试卷

### 搜索试卷

1. 点击侧边栏「搜索试卷」进入搜索页
2. 在学科下拉框中选择要搜索的学科（如「语文试卷」）
3. 在搜索框中输入关键词（如「期中」「期末」「高考」）
4. 按回车或点击「搜索」按钮
5. 服务器会并发抓取该学科所有年级分类的试卷并按关键词过滤
6. 搜索结果以卡片形式展示，包含学科和年级标签，支持下载、收藏、查看详情

> **注意**：第一试卷网没有站内搜索接口，本工具采用深度分类搜索方案，在指定学科的所有年级中抓取试卷并过滤。搜索范围越大耗时越长，默认抓取每个年级前 2 页。

### 批量下载

1. 在浏览或搜索结果页，勾选试卷卡片右上角的复选框
2. 或使用工具栏的「全选」/「反选」按钮
3. 点击「批量下载」按钮，依次下载所有选中的试卷

### 下载管理

1. 点击侧边栏「下载管理」查看下载列表
2. 已完成的下载可以：
   - 点击「打开」用默认程序打开文件
   - 点击「定位」在资源管理器中定位文件
   - 点击「删除」删除文件和记录
3. 点击「清空」清空所有下载记录（同时删除磁盘文件）

### 收藏管理

1. 在试卷卡片上点击「收藏」按钮加入收藏
2. 点击侧边栏「收藏列表」查看所有收藏
3. 支持单独下载、移除、全部下载

### 设置

1. 点击侧边栏「设置」进入设置页
2. **保存路径**：点击「浏览...」选择下载保存文件夹
3. **请求超时**：设置网络请求超时时间（秒）
4. **主题模式**：选择界面配色方案（浅色/深色/海洋蓝/玫瑰金/森林绿）

## 常见问题

### Q: 启动时提示端口被占用？

服务器会自动检测并尝试清理占用 3211 端口的旧进程。如果自动清理失败，请手动关闭占用端口的程序，或修改 `server.js` 中的 `PORT` 常量。

### Q: 试卷列表加载失败？

1. 检查网络连接是否正常
2. 确认能正常访问 https://www.shijuan1.com/
3. 查看服务器控制台输出的错误信息

### Q: 下载的文件名乱码？

文件名中的非法字符（`<>:"\|?*`）会被自动替换为下划线。如果仍有问题，请检查 Node.js 版本是否支持 gb18030 编码（推荐 Node.js 18+）。

### Q: 浏览页显示的文件类型和实际下载的不一致？

第一试卷网的元数据"文件类型"字段经常与真实文件不符（如标注 `.doc` 实际是 `.rar`）。本工具会在列表渲染后异步抓取详情页，以下载地址的扩展名纠正显示。如果纠正未及时完成就点击下载，下载逻辑仍会以下载地址扩展名命名文件，不会出现文件名后缀错误。

### Q: 中文路径无法打开文件？

服务器使用 PowerShell + UTF-8 BOM 编码处理中文路径，确保兼容 Windows PowerShell 5.x。如果仍有问题，请尝试将保存路径设为纯英文路径。

### Q: 搜索没有结果？

第一试卷网没有站内搜索接口，本工具采用深度分类搜索方案。搜索时请先选择学科，再输入关键词。如果某个年级分类的前几页没有匹配的试卷，可以尝试增加 `maxPages` 参数值（在 URL 中手动调整）以搜索更多页。也可以尝试更换关键词（如用「期末」代替「期末考试」）。

### Q: 如何修改默认保存路径？

进入「设置」页面，在「保存路径」一栏点击「浏览...」选择新文件夹，或直接在输入框中输入路径。路径支持 `~` 作为用户主目录的简写（如 `~/Downloads`）。

### Q: 支持哪些操作系统？

- **Windows**：完整支持（文件夹选择、打开文件、定位文件均使用原生功能）
- **macOS/Linux**：浏览、搜索、下载功能正常，但文件夹选择和文件打开功能需要手动输入路径
